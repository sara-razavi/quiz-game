Quiz Game
A small Python quiz game I made when I was still getting used to programming.
This was one of my early projects, so I kept the code pretty simple. The game asks a few questions, checks the answers, and keeps track of the score.
What it does

 • Shows multiple-choice questions
 
 • Takes the user’s answers
 
 • Checks if the answer is correct

 • Keeps a score

 • Shows the final result

How to run
[python quiz_game.py](./01_quiz_game.py)
